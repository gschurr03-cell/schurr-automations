Read both failure examples

Unanswered transfer: The assistant explains that no salesperson answered. With the buyer’s permission, the agreed fallback prepares a callback task for Jordan. The mock status stays “staff action pending”; it never becomes “connected.”

Task write failure: The destination does not confirm that a task was saved. The assistant says the callback has not been secured, offers the agreed main-desk phone fallback and flags an exception for a named duty manager through a separately tested route. In this mock, the exception is only displayed here. If that route is also unavailable, nothing is marked delivered.
